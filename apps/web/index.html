    连接研究模型

    使用你选择的模型服务，辅助问答、比较和总结。

    只发送固定测试文字，可能产生少量调用费用。

    资料何时发送？

    测试连接只发送固定测试文字；发起研究任务时，才将问题、相关文献节选和所选材料发送到此服务。

    API Key 不写入研究资料库或浏览器存储。

    管理当前连接

    清除连接只影响新任务，正在进行的任务继续使用原配置。

    撤销会立即禁止后续发送，并停止相关文字和页图任务；已保存内容保留。
