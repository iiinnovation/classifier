# 复杂文档解析

## 本地使用

`npm ci` 安装 Node 依赖；OCR 另外需要系统的 Tesseract 和语言包。当前开发机器已安装中英文语言包。

macOS：

```sh
brew install tesseract tesseract-lang
tesseract --list-langs
```

Ubuntu / Debian：

```sh
sudo apt-get install tesseract-ocr tesseract-ocr-eng tesseract-ocr-chi-sim
```

`.env` 中可以设置 `CLASSIFIER_TESSERACT` 为可执行文件绝对路径，`CLASSIFIER_OCR_LANGS=chi_sim+eng` 选择语言。服务启动时会继承系统 PATH；界面显示可用 OCR 语言。缺失引擎或语言包时文档会记录警告，不会把空内容当成成功识别。

## 导入方式

- **本地自动识别**：优先 PDF 文字层。文字少于 80 字的页面尝试 OCR；保留识别出更多内容的结果。适合普通文字 PDF、扫描 PDF 和带少量水印的扫描页。
- **全页 OCR**：每页都尝试 OCR，适合扫描内容与文字层混杂、文字层乱码的 PDF。已有文字层可能比 OCR 更准确，按文档情况选择。
- **视觉增强**：仅在填写独立视觉模型配置并主动选择时调用。页图会发送至该服务；本地自动模式和全页 OCR 不调用它。本次本地能力测试未调用真实视觉服务。

导入任务异步执行，显示当前页码，可取消；刷新后恢复查看任务。最多同时处理两份后台导入，单任务最多 15 分钟，每页 OCR / 视觉请求最多 60 秒。解析任务在独立 worker 中运行，避免阻塞问答 HTTP 请求。中断的导入不会自动恢复，重新导入即可。文件上限为 25 MB，PDF 上限为 500 页、提取文本 200 万字符；大量扫描页建议拆分。

## 当前支持范围

| 内容 | 本地处理 | 需要核对的范围 |
| --- | --- | --- |
| PDF 正文 | 坐标提取、启发式多栏阅读顺序 | 浮动文本框、复杂跨栏、旋转文字 |
| 扫描 PDF | Tesseract 中英文 OCR，先去除规则表格线再识别，保留词位置 | 倾斜、模糊、低分辨率、手写、数字和符号 |
| PDF 有边框表格 | 页图边框检测、单元格定位、规则矩形横纵合并、空格保留 | 不完整边框、复杂背景、跨页表格 |
| PDF 无边框表格 | 保守检测连续对齐的短文本和数值列 | 不规则列、多层表头、长单元格可能只保留正文 |
| DOCX 表格 | 原生行列、`gridSpan` / `vMerge` 合并关系 | 嵌套表格、旧式 `hMerge`、特殊容器会警告 |
| DOCX 原生公式 | OMML 转 LaTeX：分式、上下标、根式、求和积分、矩阵、括号等；保留原始 OMML | 不支持的节点标记待核对；图片 / 旧式公式对象未转换 |
| PDF / 扫描公式 | 保留可见字符、候选公式位置、页图核对 | **本地 OCR 不提供可靠的扫描公式 LaTeX 还原**；上下标、分式结构可能丢失，部分公式可能仅被识别为正文 |

没有读取出文字的 PDF 仍可保存并查看页图；界面与文档警告说明未识别页面。这类页面没有可用于回答的文字证据。跨页表格不自动拼接。

## 结构与引用

`sections[].blocks[]` 保存按阅读顺序排列的内容：

- `type`：`paragraph` / `table` / `formula`。
- `source`：`pdf-text` / `ocr` / `layout` / `docx` / `omml` / `vision` / `text`。
- `bbox`：PDF 显示页面中归一化的 `[left, top, width, height]`；包含页面旋转后的坐标。
- 表格 `rows[][]` 的单元格包含 `column`（从 0 起）、`rowSpan`、`colSpan`、`text`，覆盖位置不重复保存。
- 公式可包含 `latex`、`formulaFormat`、`originalMath`。
- `needsReview` 表示识别或推断需人工核对，并非经过校准的准确率。

引用保留 `blockId`、页码、坐标、类型、识别来源和待核对标记。表格证据文字含显式行列位置。界面显示结构化表格、KaTeX 数学排版，并支持点击引用在 PDF 页图高亮。Word 当前通过原文件核对，不生成固定页码。

Agent 的初始证据和阅读工具会携带 `needsReview`，提示模型对 OCR 数值和公式说明核对需要。引用身份校验仍不等于语义或识别准确性校验。

## 验证

`npm test` 包含图片型 PDF 的真实本地 OCR、页图生成、横纵合并表格、无边框数值表格、DOCX 分式和根式、后台任务完成 / 取消 / 重启，以及视觉响应结构校验。OCR 环境缺失时该项会明确跳过。

这些是合成回归样例，用于验证处理链路和结构保留；未建立真实科研论文集上的准确率基准。接入视觉模型后，还需用真实扫描论文检验识别效果。
