# D2 存储用量与数据保留

后续用户已同意普通删除的首版语义，SQLite 执行已实现；删除后仍按实际文件统计，不承诺 SQLite 立即缩小，备份与复制内容按规则保留。当前范围见 [普通删除实施记录](d2-deletion-execution.md)，独立诊断统计仍随 D3-04 接入。

日期：2026-10-27。对应 D2-04。工作台顶部增加“存储用量”，通过 `GET /api/storage-usage` 查看当前资料库和桌面自动备份目录。只提供刷新与关闭，不执行删除、清理、压缩数据库或归档。

## 统计范围与口径

| 区域 | 统计内容 | 边界 |
| --- | --- | --- |
| 当前资料库文件 | 原文件、JSON 记录与历史、SQLite 数据库与 WAL／SHM、隔离副本、文件操作／迁移记录、其他文件 | 使用文件字节长度和文件数；各分类相加等于本次读取的资料库文件总量 |
| 自动备份与保全副本 | 桌面配置目录下的 `library-backups` | 独立于当前库显示，可能包含切换前的其他资料库；由主进程配置路径，HTTP 参数不能指定扫描目录 |
| 记录正文／历史内容 | 有效记录数、归档数、历史版本数，当前内容与各历史版本的紧凑 JSON UTF-8 字节数 | 内容量估算，不含格式空白、数组分隔符、索引及数据库开销；已包含在文件统计中，不应再次相加 |
| 未统计范围 | 用户另存的目录／ZIP 备份、导出文件、其他资料库、草稿／缓存、系统日志与崩溃报告 | 未知范围显示“未统计”，不能当作零占用；独立诊断存储尚未实现，后续随 D3-04 接入 |

文件大小不是磁盘实际分配空间或可回收空间。硬链接按路径累计，压缩、稀疏文件、APFS 共享块及文件系统元数据没有被转换为可释放字节。归档只改变展示状态，原件、研究内容和历史继续保留，不释放空间。

统计是扫描期间的观察值，不是一致备份或删除许可。导入、编辑、模型任务和备份维护可能改变文件；页面提示在任务结束后刷新。扫描发现目录／JSON 文件变化、无法读取、符号链接、特殊文件、损坏记录或达到限制时，返回并显示“不完整”，保留已读部分，不把跳过项报告为已完整统计。

## 实现与只读边界

- JSON 记录逐文件读取，使用现有记录解码规则；损坏原件仍计入文件大小，但不进入有效内容估算，也不触发隔离写入。
- SQLite 使用资料库已持有的连接同步遍历记录，不为统计新开 WAL 连接，避免新建辅助文件。不会执行写入、checkpoint 或 VACUUM。SQLite 现有 SHM 协调字节可能因读取发生变化，不能据此声称所有控制文件逐字节不变。
- 递归扫描不跟随符号链接、不读取原件或备份正文；JSON 打开采用 `O_NOFOLLOW` 并核对文件身份。目录和文件时间／身份核对发现变化时标记不完整。这不是对外部进程恶意并发替换路径的完整文件系统沙箱。
- 单次扫描最多 200,000 个文件／目录／SQLite 行、64 层目录、15 秒检查预算和 256 MiB 已解析记录字节；单记录仍受既有 32 MiB 限制。它们是遍历检查上限，不承诺单次系统调用或同步解码的硬实时截止。
- 同一服务合并重叠请求；HTTP 返回 `Cache-Control: no-store`。POST／DELETE 没有执行接口。关闭弹窗后的旧响应不能覆盖重新打开的页面。
- 桌面主进程通过私有启动通道传入自动备份目录；Web 开发未配置该目录时明确显示未统计。不存在的受管备份目录计为零且不会被创建；与资料库重叠或不安全的范围不会被当作独立完整总数。

普通删除与彻底清除的产品选择仍待确认，本功能不替代 D2-02 删除事务；后续 D2-03 的独立进展见 [来源状态说明](d2-source-states.md)。备份、隔离和导出文件可能保留内容，页面保留这些说明。
