# UX-02：任务式 AI 研究首轮实现

日期：2026-10-19。用户批准开始构建后实现。当前仍为 Mac x64 预览范围，Windows 与 Mac ARM 延期；没有迁移、删除或向模型发送真实用户资料。

## 用户路径

1. 在右上角“模型连接”填写完整 Chat Completions 地址、模型名称和 API Key，启用本次连接。
2. 打开主题，导入或关联文献。在研究任务区说明目标，确认 2–12 篇所选文献；默认选择主题内未排除的文献。
3. 开始任务。AI 从标题和有限开头节选建议 1–6 个维度，再按维度检索相关原文与笔记并生成比较草稿。
4. 草稿直接呈现比较结果、条件、缺失状态及引用。可以打开保存的摘录、回查原文并返回；核对后明确采用。
5. 点击“生成研究总结”，系统自动选用当前比较表快照并生成带引用的总结草稿。明确采用后可编辑、查看历史和导出 Markdown。
6. 需要调整时在比较页填写后续要求，如“增加样本量，重点比较方法”。当前重新生成整份比较提案，采用时才更新全部内容；旧版本保留。

普通路径不需要预先填写笔记、逐个配置维度、逐格填写或重新勾选成果材料。空比较表在任务进度／有效草稿展示期间隐藏，避免重复展示空表单。人工比较和原有单列建议继续可用。

## 状态、冲突和来源

- 整份比较任务 `comparison-draft` 最多 300 秒，显示规划与维度进度，支持停止、刷新后重连、失败后重试；不自动恢复模型调用。
- 初始比较创建、整份草稿和总结生成支持明确请求标识。响应丢失后的原请求可重试，避免重复创建或重复调用；不同在途目标不会被伪装为已提交。
- 生成不写入已保存的比较内容；采用一次写入新版本。比较修订、文献范围／关联、所有所选原文版本、参与取证的笔记修订在完成／采用时校验。即便某篇文献未命中证据，版本变化也会阻止采用。
- 旧草稿按任务原始文献范围展示，调整当前范围后可参考，但不可直接采用；来源已变的总结草稿也禁止采用。
- 总结沿用既有材料、证据快照、段落引用、版本、草稿及人工修订保护。同一比较版本重复进入总结会复用同一成果。
- 引用校验检查来源身份和取证范围，不保证文字与判断在语义上必然被引文支持。

## 会话模型连接

`GET/PATCH /api/settings/text-model` 沿用同源和桌面实例认证。密钥不在响应中返回，不写入资料库或浏览器存储。远程地址须 HTTPS，本机 HTTP 仅允许回环；不接受含用户凭据、查询参数或片段的设置地址。外部环境提供的地址在界面呈现时移除这些部分。

配置仅存当前后端进程内存。桌面退出后需重新连接；Web 环境变量不会被覆盖，重启时仍按原环境加载。更新／清除只影响新任务，在途任务使用启动时快照，可在任务页停止。此功能不等于系统凭据保存、连接测试或完整授权撤销，D3 继续进行。

## 尚未完成

- 成果仍使用现有段落编辑器；尚未实现连续文稿编辑体验。
- 后续要求重生成完整草稿，不是对单列／单段的自动合并，也不自动筛掉文献。
- 规划与比较读取有限节选，不代表全文阅读；检索未命中不能解释为论文未报告或领域空白。
- 没有调用真实外部模型服务；输出质量、遗漏与修订成本仍需 D4 验收。
- 会话配置暂无连接测试、系统凭据保存或无密钥专用选项。
- D1 恢复界面、完整文件操作日志等原有任务继续保留；当前改动不等于 D1–D5 全部完成。
