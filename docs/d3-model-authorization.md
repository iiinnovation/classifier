# D3 模型授权撤销

日期：2026-10-28。对应 D3-02，并补充 D3-01 的会话设置入口。本轮实现文字／页图授权撤销；系统凭据、连接持久化、连接测试和完整发送告知仍待 D3-01，D3 整体保持进行中。

## 使用行为

模型设置中的“更换连接”和“清除连接”保留现有任务配置快照规则：新任务使用新设置，已经启动的任务继续使用原地址与密钥。新按钮“撤销模型授权”清除文字与页图连接，立即禁止对应授权下的后续发送，并请求取消相关任务；本地解析、原文检索和已保存的研究内容继续可用。任务状态在取消及清理结束后更新，已提交的导入遵循原子提交边界。

连接仍默认只在本次会话有效，密钥不落入资料库或浏览器存储。本轮已就记住连接的默认选择和在途处理向用户提出可选问题，尚未收到具体选择；撤销行为沿用[既定交付方案](desktop-release-plan.md#运行时配置与在途任务)，没有把“继续任务”记成新的持久化设置决定。

## 发送边界

- 配置提供器分别持有文字与页图授权信号。普通配置更新保留授权；撤销使旧任务及更新前后捕获的快照一起失效。只有明确设置新连接才能创建新授权，旧快照始终保持已撤销状态。
- 任务在准备资料、读取记录或写入排队状态之后，仍绑定捕获时的授权。问答、笔记建议、比较规划／逐列整理和成果生成在每次实际调用前重新检查取消，覆盖进度事件等待期间的撤销。
- 撤销优先于开发测试的注入配置，不能通过 `qaOptions.config` 恢复已撤销的远程调用。撤销后可继续本地搜索；显式重新连接后新模型任务才可发送。
- 视觉解析工作进程把页图经 IPC 交给后端，由后端使用任务快照和取消信号请求供应商并校验返回结构。生产导入的模型地址与密钥留在后端内存，工作进程不直接发送模型请求；取消和进程退出会中止该任务的网络请求，并等待清理完成。
- 分别撤销文字或页图授权不会取消另一类任务；不自动重新调用已取消任务。刷新或服务重启只读取任务状态。

生产接口：`POST /api/settings/model-authorization/revoke`，JSON 为 `{"scope":"all"}`、`{"scope":"text"}` 或 `{"scope":"vision"}`。响应仅包含安全的设置摘要和撤销范围，使用 `no-store`；沿用同源与桌面实例认证，非法范围在更改授权前拒绝。页面撤销按钮使用 `all`。
