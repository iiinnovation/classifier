## 本轮结论与下一步

D1 整体仍不标“完成”。当前证据支撑现有恢复机制；真实发行版本配对、最低／干净机器和发布资格不由格式样本或本机通过代替。硬件断电没有实测，也不要求通过切断开发机电源来继续开发。

本次核对后已实现 D2-01 的只读影响预览，独立源码回归及边界见 [D2 预览记录](d2-deletion-preview.md)：它只展示目标、关联、复制／历史内容和活动任务，不能执行删除或变更研究资料。产品语义仍待确认。D2-02 的执行事务、任务协调、来源状态和中断恢复必须单独实现、测试，并由用户在实际操作时确认具体范围。

现有方案默认区分“移出主题”“删除原文但保留引用摘录”“删除主题但保留共享文献”“删除研究记录但保留被复制的材料”。彻底清除的首版范围仍需确认；备份和已导出文件不会被普通删除隐式清除。
