## 使用方式

点击右上角“模型连接”，填写完整 Chat Completions 地址、模型名称和 API Key。可以先点击“测试连接”，再启用；测试不会启用新配置，也不会创建研究任务或读取资料库。测试只发送固定文字 `This is a synthetic connection test. Reply only with OK.`，可能产生少量调用费用。

默认只在本次应用运行使用连接。选择“记住连接，退出后继续使用”后，退出重开可以恢复；重开只读取设置，不自动测试或发起模型请求。页面不会返回或填回 API Key，同一接口留空可以保留已有密钥；更换地址须重新填写。

状态区分未连接、已配置／已记住但尚未测试、已测试。通过状态仅在当前后端运行中保留，绑定接口、模型和密钥，最多有效 10 分钟；连接测试只证明对话接口能响应，不证明工具调用、引用质量或所有研究流程兼容。认证、额度、接口不存在、限流、超时及无效响应均显示可读错误，不转述服务端响应正文。

## 设置保存和授权

Mac 上使用 Electron `safeStorage` 的异步系统加密能力，由 macOS 钥匙串支持保护。独立配置文件为 `<应用用户目录>/model-settings.json`，默认位于 `~/Library/Application Support/Classifier/`，使用自定义用户目录时跟随该目录。URL 和模型名称可读；密钥与对应的 URL／模型一起加密，防止密文被挪到不同配置后恢复。

这不是每个服务一条原生钥匙串密码条目；文件中保存加密密文，系统保护其解密能力。密钥不进入研究资料库、资料库备份、浏览器存储、命令行或日志。设置写入采用独立临时文件、同步和原子替换，大小上限 64 KiB；本轮只在 Mac 启用记住能力，保护不可用时提供会话连接。

损坏／不可解密的旧文件保留原字节并显示警告，允许临时会话连接；覆盖记住前需要清除旧设置。清除失败会先禁止新任务使用连接，并提示重开可能恢复，成功重试后清除旧警告。

| 操作 | 新任务 | 在途任务 | 已记住的连接 |
| --- | --- | --- | --- |
| 启用新配置 | 使用新配置 | 保留启动快照 | 按“记住连接”的选择保存或清除 |
| 清除连接 | 停止使用模型 | 保留原配置，可主动停止 | 成功后删除 |
| 撤销模型授权 | 禁止发送，须显式重新启用 | 立即取消授权信号并停止相关请求 | 成功后删除，退出重开仍无连接 |

文字／页图撤销仍按原有范围执行，页图撤销不取消文字连接测试。慢加密保存期间“撤销模型授权”保持可用，旧保存完成不能重新启用已撤销的配置。后端维护重启沿用主进程内的当前会话设置；普通完全退出仍忘记未选择记住的连接。上游模型调用与连接测试均拒绝 HTTP 重定向。
