# D0 review 与修复（2026-10-11）

范围：当前未提交的 D0 桌面、解析进程、设置／API 适配、关闭逻辑及资源测量改动。按严重程度记录以下问题，修复未改变研究数据格式。

| 级别 | 问题与触发 | 修复 |
| --- | --- | --- |
| P1 | `imports.mjs` 的退出回调 `(code, signal)` 遮蔽外部 AbortSignal。正常退出留下 abort 监听；被信号终止时对字符串调用 `removeEventListener` 会抛出异常，导致任务不结算。 | 改名 `exitSignal`；正常、取消及启动失败都清理监听与计时器。 |
| P1 | `fork()` 启动失败可只发出 error/close、不发 exit；原实现一直等待 exit，任务和并发槽位无法释放。 | 子进程以 close 结算；worker 仍以 exit 结算。实际不存在的可执行路径回归检查 ENOENT 及时返回。 |
| P1 | 导入／模型任务先等待 queued 写入，再注册到任务集合；此时 stop 会提前返回，可能在应用退出后继续落盘或开始模型工作。导入等待主题读取后也未重新检查 stopping。 | 入场即注册关闭等待；初始写入失败也释放等待；主题查询后重查关闭状态；模型工作调用前检查取消。可控磁盘等待回归先失败、修复后通过。 |
| P1 | 同步 `POST /api/documents` 未进入 imports 任务集合，shutdown 不取消／等待它；其他在途请求写入也未等待。 | server 关闭时停止接收新工作，取消同步解析，等待在途请求处理完毕后返回。打包测试新增同步 PDF 正在 OCR 时关闭、无文献落盘和无残留进程的验证。 |
| P2 | 取消测量及生命周期测试仅按进程名匹配 Tesseract，可能在 `--list-langs` 探测期间触发；界面解除 disabled 也不代表确实取消。 | 仅将含 `tessedit_create_tsv=1` 的识别命令计为正在 OCR，不保存完整命令行；每轮核对任务状态 cancelled 且无 documentId。旧报告无法证明每轮都进入了识别阶段，保留为历史并补测。 |
| P2 | 启动过程中退出，ready 的异步续体仍可能创建窗口并弹启动失败框。 | ready 前后检查 quitting，退出期间不创建新窗口或显示失败对话框。 |

测量器另将采样任务错误及时接住，避免应用异常退出时产生未处理拒绝；中英文内容检查由整篇匹配改为逐页匹配。

已执行：66 项 Node 测试通过（新增 6 项生命周期回归）；现有 6 项开发入口桌面测试通过；重建后 7 项打包桌面测试通过。真实 OCR 取消测量的 10 个任务全部核对为 cancelled，等待及采样后 RSS 增长 **45.7 MiB**，通过 100 MiB 门槛，OCR 进程残留为 0。结果见 [review 验证记录](measurements/d0-review-mac-x64/validation.json) 和 [原始测量](measurements/d0-review-mac-x64/cancel.json)。未改动传输／界面业务实现，本轮不重复 38 条业务测试；上一轮 Electron 与 Chrome 各 38 条通过的日期及构建边界继续保留。

历史资源报告对应旧 ASAR，不能用于声称这次 review 修复构建全部资源门槛通过。D0 跨平台、最低配置及干净机器验收仍未完成。

## 后续补修（2026-10-13）

解析结束后的原文件写入仍有取消空档：异步导入可在 `stop()` 后继续写文献并标为 completed；同步导入在解析后过早移除取消控制器。现将原文件保存后的取消检查作为文献提交边界，取消时清理已保存的原文件；提交已开始的任务由关闭流程等待完成。可控写入测试覆盖用户取消、异步关闭、同步关闭及提交期间关闭。

补修后 70 项 Node 测试、7 项桌面开发入口测试通过。本次未重建分发包，以上新包资源指标缺口不变。
