# UX-01d：成果文稿编辑首轮

日期：2026-10-21。用户批准按产品梳理建议继续构建，先改善成果编辑，并推进 D1 恢复基础。本轮未调用真实模型服务，尚无真实研究任务质量结论。

## 当前体验

- “编辑正文”打开连续页面样式的文稿，正文随输入展开；已有成果默认聚焦第一段。
- 保留各段章节标题、原有段落 ID 与引用归属。新增段落沿用上一段章节，默认仍是用户判断。
- 研究问题默认收起；段落类型、引用选择、排序和移除放在“段落设置”内。折叠摘要仍显示判断类型和引用数量，已选引用可直接回查。
- 本次编辑期间可撤销移除段落；显示段落数和字符数，达到 40 段后禁用新增和撤销移除。保存仍显式触发，沿用服务端的总字数、引用和来源校验。
- 关闭编辑、刷新恢复、查看原文及版本冲突仍使用原有草稿和版本机制。服务器数据格式不变。

这是段落保留引用的文稿编辑首轮，不是单一富文本编辑器；跨段自动合并／拆分、指定段落 AI 修订、连续键盘段落导航尚未实现。移除撤销栈仅在当前编辑器中保留，已保存版本可通过历史恢复。
