# M3：多文献比较

状态：2026-10-08 已完成并验证。

范围：围绕研究问题选择文献和比较维度，从 M2 笔记或原文整理比较项，记录适用条件、可比性及共识／分歧，人工确认后保存。当前阶段不生成 M4 的综述或导出成果。

## 数据与交互约定

- 每个主题可以保存多个比较表。表包含标题、研究问题、2–12 篇显式选定的文献、1–12 个自定义维度，以及按“文献＋维度”标识的单元格。
- 单元格保存值、信息状态（未填写／已记录／未报告／未找到／不适用）、判断类型、适用条件、可比性（待判断／可比较／有条件可比／不可直接比较）及理由。
- 从笔记取值时绑定笔记 ID、版本与当时内容，并复制原文证据；从原文取值时绑定文献 ID、片段及解析版本。读取后提示笔记或原文是否变化，不隐式改写既有单元格。
- 每个维度有一条可编辑的综合判断，记录共同点、差异、冲突或材料不足，保存所依据行的快照与证据。修改基础单元格后提示综合判断需要复核。
- 表、单元格、综合判断都通过表版本做并发检查，每次写入保存历史。删除行或维度的数据仍保留在历史版本中；恢复历史形成新版本。比较表可归档。
- 新建或扩充文献范围只接受当前主题关联文献。已移出的文献在旧比较表中保留并标明状态；新模型任务要求所选文献仍在当前主题内。

## 模型建议

按一个维度对所选文献生成建议。服务端从这些文献的当前笔记、已选证据及关键词检索中准备有限原文，并分配包含文献身份的引用 ID。输入区分用户笔记与原文；输出逐行返回信息、条件和可比性，另给出跨文献综合判断。

方法、研究对象、主要发现、局限及已支持别名使用中英文关键词扩展，优先读取对应章节正文；未命中时补充摘要、引言、结论或有限正文样本。自定义维度继续按名称与说明检索，可在说明中补充英文关键词。输入注明检索策略及 `partial: true`，其中 `context_sample` 只表示补充上下文，不表示已找到该维度的证据，也不代表完整阅读论文。

只有实际发送的原文可以被引用；单元格只能引用本行文献，跨文献判断的引用须来自所选范围。未找到证据不等于论文未报告，更不等于整个领域存在研究空白。模型的身份／结构校验不替代人工检查证据是否支持结论。

任务复用现有 90 秒超时、取消、容量控制与重启中断机制。任务结果只作为建议展示。“采用本列建议”经用户明确操作后原子更新该列与综合判断；原数据进入历史。研究问题、选定文献、维度定义或目标单元格在任务启动后变化时，旧建议不能覆盖它们。

## 实施与验收

1. 创建和编辑比较表、调整文献与维度、归档及历史恢复。
2. 从笔记和原文编辑单元格，保存缺失、条件和不可比原因，并准确回查出处。
3. 人工记录跨文献判断，标记依据变化与核对状态。
4. 生成、审阅和采用模型建议；检查引用越界、伪造、缺失信息、取消、并发和旧建议保护。
5. 浏览器完成主题进入、比较编辑、来源跳转、刷新与服务重启恢复，验证移动端；回归 M1–M2。
6. 使用真实论文验证多文献数据与引用各自归属。

设计与代码独立实现。Agentero 用于理解交互与研究流程，未复制其采用 CC BY-NC-SA 4.0 的深度研究模板或提示词。

## 实现与验证

存储位于 `data/comparisons/`，接口见 [API 约定](api.md)。主题页“多文献比较”进入表格；可调整范围与维度，逐格编辑、核对出处，并通过“跨文献判断”记录差异。原文查看后可直接返回比较表。当前标签页的未保存表单在刷新后可继续；所有保存操作使用版本检查。

模型读取每篇最多 6 个、合计最多 6000 字的原文片段，完整上下文最多 100000 字符；任务与问答共用最多 3 个活动任务、90 秒超时。生成过程和测试都不自动执行外部检索。提示词与 JSON 合同在本项目独立实现。

| --- | --- |

## 2026-10-08 审查修复

1. 默认中文维度直接用于字面检索，导致英文论文没有证据进入模型。补充标准维度的中英文关键词与章节检索，并明确标记有限阅读和补充上下文，原文保持不变。
2. 并发删除维度后“加载最新”会抛错并清除草稿。现先检查目标是否仍存在，成功建立替代编辑器后才清理旧草稿；维度或文献已移除时保留输入，刷新后仍可打开只读草稿查看、复制。
3. 历史引用只依据当前选定文献校验，导致已移除行无法打开未变化的原文。历史接口现独立读取历史文献的解析版本并派生校验状态，不改写历史快照，也不扩充当前比较范围。

修复后用上述两篇英文 PDF（分别解析为 635、940 个片段）在没有笔记或人工选证的情况下复验四个默认中文维度：每个维度均从每篇论文读取 6 个原文片段，单篇单维度共 437–1607 字符；来源均属于所选论文，文字与原文完全一致，满足每篇及整体输入上限。使用模拟模型检查实际输入，不将检索通过视为研究结论质量通过。以上修复已纳入 40 项 Node 测试与 29 条浏览器回归。

当前交付止于 M3。后续 M4 将基于笔记、比较表和证据形成可编辑研究总结与导出成果。
