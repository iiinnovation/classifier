# Classifier 产品框架与路线图

更新日期：2026-10-08。

定位与首版任务已在产品讨论中确认；M1–M3 已完成，M4 仍待开发。以下功能拆分、实施顺序和验证方案作为后续开发依据。当前能力见 [README](../README.md)，运行限制见 [产品与架构边界](product-boundary.md)，阶段验收见 [M1](m1-implementation.md)、[M2](m2-implementation.md) 和 [M3 实现说明](m3-implementation.md)。

## 1. 产品定位

面向跨学科科研人群的文献研究工作台：帮助研究者围绕一个研究问题，收集和理解文献、比较研究证据，形成可追溯、可持续更新的研究成果。

优先服务需要反复阅读、比较和整理一组文献的研究者。以研究任务的共性组织产品，通过可调整的字段与模板承接学科差异。面向广泛学科是产品方向，各学科的实际适用程度需要用真实材料验证。

核心任务：用户带着一个研究问题和一组文献进入，完成阅读与比较，得到一份可以逐条核对出处的研究总结；之后还能回来继续修改。

功能优先级依据：是否帮助研究者更可靠地完成这项任务，并留下可继续使用的成果。

## 3. 围绕研究问题组织工作

产品流程：研究问题 → 收集与筛选文献 → 阅读与证据记录 → 比较与综合 → 编辑和保存成果 → 随新材料继续研究。

| 环节 | 用户任务 | 保留的成果 |
| --- | --- | --- |
| 收集与筛选 | 导入已有文献、记录相关性和纳入或排除理由；后续补充外部检索 | 有组织的文献集合与筛选记录 |
| 阅读与理解 | 理解研究问题、方法、结果和局限，追问关键细节 | 带出处、可编辑的阅读笔记 |
| 比较与综合 | 按明确维度比较研究，记录共识、分歧和证据缺口 | 文献比较表与待验证问题 |
| 写作与积累 | 根据证据组织论述、修订结论，加入新材料继续工作 | 带引用的研究总结或综述草稿 |

主入口以研究主题组织。进入主题后能够看到研究问题、关联文献、当前笔记与成果，并恢复之前的工作。现有单篇阅读界面承担主题中的深入阅读任务。

首版工作区分为主题概览、文献研读、证据比较、研究成果四个工作区域；具体导航与布局在对应阶段设计。

## 4. 核心内容及其关系

以下是产品概念，具体存储结构和 API 在实现阶段定义。

| 内容 | 需要表达的含义 |
| --- | --- |
| 研究主题 | 研究问题、范围、关联文献和阶段性进展 |
| 文献 | 原文件、基本书目信息、解析版本和阅读状态；一份文献可以关联多个主题 |
| 证据 | 所属文献、原文片段、页码或段落定位、识别来源及待核对信息 |
| 阅读笔记 | 原文报告、模型归纳或用户判断，及其引用与编辑记录 |
| 比较表 | 用户选择的比较维度，各文献对应内容、出处和可比性说明 |
| 研究成果 | 围绕问题组织的可编辑总结、引用、分歧和待验证事项 |

证据在跨文献场景中需要同时标识所属文献与片段，不能仅依赖单篇文档内部的片段 ID。重新解析后，已有笔记和成果的引用应保持对应原证据版本，或明确标记需要重新核对，不能悄悄指向新内容。

从主题移除文献关联时，应保留被已有成果引用的来源。成果编辑和补充材料应保留已保存版本；重新生成前需要让用户决定是否采用新结果，避免覆盖人工修改。

## 5. 深度要求与学科差异

### 可追溯的结论

由文献支持的结果和归纳需要关联实际读取过的证据。用户能够从笔记、比较表或总结回到原文。引用存在只说明来源身份有效；是否真正支持判断，仍需要提供人工核对和修正入口。

### 带条件的比较

比较时同时展示研究对象、方法、条件和指标定义，记录缺失信息与不可直接比较的原因。单位或指标含义不明时保留原值和原文表述。首版以整理和辅助判断为主，不自动作跨研究的数值合并或统计推断。

### 区分证据与判断

区分原文报告、模型归纳与用户判断。假设或待验证问题可以单独保存，但不能呈现为已有证据支持的结论。区分未报告、不适用、未找到和未核对，保留 OCR 等识别来源的待核对标记。

### 可修订、可积累

用户可以修正提取结果、调整比较字段、编辑成果和补充证据。修改判断后，相关引用需要重新核对；加入新文献后可以生成修订建议，并由用户选择采纳。

### 通用字段与可调整模板

通用字段覆盖研究问题、材料或对象、方法、主要发现、限制与出处。字段允许为空、调整或扩展：

- 医学研究可关注人群、干预、对照和结局。
- 计算机研究可关注数据集、方法、评测设置和指标。
- 人文研究可关注论点、史料或文本、论证路径和解释分歧。

首版提供通用字段与人工调整能力，专门模板根据试用需求逐步增加。不能要求每类研究都具有实验、样本或量化结果。

## 6. 当前基础与首版范围

当前已完成 M1 文献组织、M2 阅读笔记和 M3 多文献比较：包含主题、文献关联、书目信息、筛选阅读状态、结构化笔记，以及带证据和条件的可编辑比较表、跨文献判断、历史版本与模型建议。原有导入、解析和单篇问答继续作为基础。研究总结与导出仍待开发。

首版以用户提供的一组文献为起点，包含：

1. 研究主题及文献关联、基本书目信息的人工维护、筛选理由和阅读状态。
2. 通用结构化阅读笔记、来源定位、人工纠正和保存。
3. 主题内多文献比较、比较字段调整、逐项证据与可比性说明。
4. 基于所选证据形成研究总结，支持人工编辑、保存、再次打开及 Markdown 导出；导出保留来源清单和页码或段落定位。

第一阶段继续采用本机单用户运行方式。公开部署、团队协作、外部学术检索、URL 导入、DOI 自动补全、订阅追踪、专门学科模板和自动主张核验排入后续评估。是否引入数据库或向量检索，由具体功能与验证结果决定。

## 7. 实施顺序与阶段验收

| 阶段 | 交付内容 | 阶段验收 |
| --- | --- | --- |
| M1 研究主题与文献组织（已完成） | 主题创建与编辑、关联已有或新导入文献、基本元数据、筛选与阅读状态 | 已验证同一文献用于不同主题；切换主题和重启后关联与状态正确；已有文档仍可直接打开 |
| M2 阅读笔记与证据（已完成） | 可编辑的结构化笔记、证据关联、人工纠正与保存 | 已验证引用返回原文、缺失状态、人工修改恢复；模型建议不覆盖笔记；解析变化保留原文快照 |
| M3 多文献比较（已完成） | 自定义比较维度、从已读取证据生成比较建议、记录条件和分歧 | 已验证比较项回查证据、来源与范围校验、缺失状态、条件说明、旧建议保护及重启恢复；结论含义由用户复核 |
| M4 研究成果 | 根据所选材料与证据组织总结、编辑与版本保存、Markdown 导出 | 引用可核对；人工修改不会被新生成结果覆盖；重启后可继续编辑；导出包含来源与定位 |

按 M1 → M2 → M3 → M4 推进，每阶段验证后调整下一阶段范围。M1–M3 已按“数据模型与接口 → 工作台 → 验收”的顺序完成；当前交付止于 M3。

## 8. 首版整体验证

建议准备至少三类研究材料，覆盖实验或定量研究、计算或方法研究、人文论证材料。每个任务先使用约 5–10 篇实际文献，由熟悉材料的人给出要回答的研究问题、关键证据和比较条件。这是验证方案，不代表已具备跨学科评测结果。

完整验收流程：

1. 创建研究主题，导入文献，记录筛选决定。
2. 阅读并纠正笔记，检查引用是否落到正确来源。
3. 按研究问题比较文献，检查遗漏、分歧和可比性。
4. 生成并编辑总结，逐条核对关键结论及其证据。
5. 重启后恢复工作，补充一篇文献并修订成果，检查历史修改和引用。
6. 导出成果，确认离开工作台后仍能识别所用文献和原文位置。

记录引用定位是否正确、判断是否受到证据支持、错误与遗漏的修正量、成果是否保存完整，以及完成任务所需时间。与同一研究者原有工作方式比较，同时记录核对成本。首轮建立基线，再确定量化指标与通过阈值。

## 9. 待真实使用验证的判断

- 首批高频任务更偏向选题调研、专题综述还是方法比较。
- 通用阅读字段在哪些研究类型中不足，哪些需要专门模板。
- 用户是否能提供足够文献完成任务，外部检索是否需要提前。
- 可编辑比较表和研究总结能否直接进入用户现有的科研工作流。

这些问题通过材料试用和反馈逐步回答。后续范围变化应同时更新本文件的首版范围与实施顺序，当前实现说明仍以 README 和 API 文档为准。
