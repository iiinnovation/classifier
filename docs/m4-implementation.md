# M4：研究成果

状态：2026-10-08 首版已实现并通过功能验收。

2026-10-09 完成审查修复并纳入 [M4 收尾基线](m4-closeout.md)。后续交付能力和遗留工作统一见 [工作清单](work-items.md)。

范围：在研究主题内选择阅读笔记、比较表或原文片段，组织可编辑的研究总结；保存证据快照、历史版本及未保存草稿；导出包含来源与定位的 Markdown。模型生成供审阅的替代草稿，明确采用后才更新正文。

## 数据与交互约定

- 每个主题可保存多份成果。成果包含标题、研究问题、材料快照，以及有章节标题、判断类型、正文和引用的段落。
- 添加或更新材料必须显式选择。来自笔记和比较表的条件、可比性与缺失状态随快照保留；引用同时绑定文献与解析版本。更新材料不改写正文的旧引用。
- 原文报告、模型归纳、用户判断、待验证问题分别标识；原文报告和模型归纳必须引用已选证据。人工改写后重新待核对。
- 保存使用版本检查，历史恢复产生新版本。来源变更和主题移除保留已保存成果，原文变化时阻止错误定位。
- 模型只读取明确选择的材料与有限证据，复用容量、超时、取消及重启中断控制；采用前检查成果及来源是否变化。
- Markdown 导出包含成果版本、判断类型、核对状态、来源清单、原文摘录和页码或段落定位，可以离开应用核对来源。

## 验收范围

1. 选择笔记、比较表和原文，编辑、核对并保存成果；跨主题和伪造引用被拒绝。
2. 输入冲突、迟到响应、刷新及重启后保留人工内容；恢复历史形成新版本。
3. 重新生成不会自动覆盖正文；成果或来源变化后拒绝采用旧建议；取消与重启可恢复状态。
4. 来源变化、移除后保留历史证据；导出可识别文献、位置和旧版本。
5. 完成浏览器、手机布局及 M1–M3 回归，并用真实论文验证导出引用归属。

## 实现与验证

主题页“研究成果”进入成果工作区。创建后可选择笔记、比较表或原文片段，点击“将所选材料加入正文”按快照整理材料，也可直接添加段落。编辑章节、判断类型、正文和引用后保存，逐段核对出处；来源跳转后可返回成果。未保存编辑按成果与编辑类型保留在当前标签页，刷新后可以继续。

存储位于 `data/reports/`，接口与限制见 [API 约定](api.md)。每份成果最多选择 20 组材料、120 个原文片段，最多 40 段正文、总计 30000 字符。模型只接收明确选定的材料，完整输入最多 100000 字符；与问答、比较共用 3 个活动任务和 90 秒超时。未配置模型时，材料整理、手工编辑与导出均可用。

| 验收项 | 结果 |
| --- | --- |
| 材料、条件与引用 | 笔记、比较表、原文可整理为段落；保留缺失状态、不可比原因及引用；跨主题、伪造引用与模型来源被拒绝 |
| 保存、核对与历史 | 并发更新返回冲突；历史恢复形成新版本；编辑或依据变化后重新待核对 |
| 草稿与异步边界 | 刷新后恢复；迟到的版本响应不覆盖新输入；创建响应丢失后保留修订并恢复已有成果 |
| 模型草稿 | 生成不修改正文；明确采用才替换；成果或来源变化后拒绝旧草稿，失败或取消保留人工内容 |
| 原文变化与移除 | 移出主题后可查看未变化的原文；解析变化保留旧摘录并阻止错误跳转，历史引用同样校验 |
| Markdown | 保留成果版本、判断类型、核对状态、书目信息、原文摘录与定位；正文中的 HTML、图片和链接语法按文字导出 |
| 重启与手机 | 服务重启后正文和导出一致；1440px／390px 浏览器验证通过，页面无横向溢出 |

2026-10-09 外部评审处理后的完整回归：`npm test` **49 项通过**；`CLASSIFIER_BROWSER_CHANNEL=chrome npm run test:e2e` **38 条通过**。测试见 [成果 HTTP 测试](../tests/reports.test.mjs)、[成果浏览器流程](../tests/e2e/reports.spec.mjs) 与 [材料草稿和原文跳转回归](../tests/e2e/reports-recovery.spec.mjs)。测试使用独立临时数据和受控模型响应，不修改实际资料。

真实材料验收使用 [Attention Is All You Need](https://arxiv.org/abs/1706.03762) 和 [Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401)：导入后分别选取第 2 页的原文片段，经比较表整理为成果并导出。导出的文献身份、片段 ID、页码和保存摘录均对应正确，重启前后导出一致。原始 PDF 和导出样本保留在临时目录，未加入仓库。

上述验证确认功能、来源身份和恢复行为。实际模型的结论质量、完整研究任务中的修订成本，以及跨学科适用性仍需按 [整体验证方案](product-framework.md#8-首版整体验证) 用真实研究任务建立基线；首版不自动核验主张含义，也不进行跨研究统计合并。

## 2026-10-09 审查修复

1. 合法成果经材料追加后可能超过原有 128 KiB 的 JSON 请求上限，导致无法继续编辑。成果编辑接口现使用独立的 1 MiB 上限，继续校验段落数量、正文长度和引用范围；其他接口保持原上限，超限信息显示实际限制。回归覆盖 40 段、29424 字符、超过 128 KiB 的成果再次编辑、重启与导出。
2. 原文材料草稿恢复后，选择仍保留但候选列表没有对应文献。现将草稿中的材料补入列表，显示选择状态及片段数量；切换勾选和重新渲染保留原版本与片段选择。文献已移出主题时仍显示可取消的材料项。
3. 编辑中核对已保存版本并回查原文时，编辑弹窗会遮挡阅读器。现先持久化草稿并关闭弹窗，再打开原文；返回成果、刷新或原文加载失败后，均可继续原输入。

回归用例见 [成果容量测试](../tests/reports.test.mjs) 与 [材料草稿和原文跳转测试](../tests/e2e/reports-recovery.spec.mjs)。所有测试使用独立临时数据目录。

## 2026-10-09 外部评审后续处理

“将所选材料加入正文”按材料条目的身份、内容、条件和证据去重。重复点击没有新内容时返回当前成果，不新增段落、版本或历史；原段落的人工修订与核对状态保留。新选材料发生变化时只追加变化的条目，已删除的材料段落可以重新加入。书目信息或核对状态变化不会单独生成重复段落。

新增材料段落在来源中保存条目指纹。旧版成果缺少指纹时，从该段落最早保存的材料与正文快照识别原条目，兼容人工修订；若旧数据不足以识别，则保守跳过该来源，避免重复插入或覆盖，必要时可在核对后手工整理。

笔记整理出的段落现在包含文献前缀，与比较项一致。材料的可信来源由服务端显式传入校验器，不再将新增段落当成既有段落来继承来源；客户端仍不能伪造模型身份。

外部提出的 8 项问题、事实修正、运行与数据保留边界，以及性能／前端维护待办，统一见 [整体评审记录](review-m1-m4-2026-10-09.md)。
