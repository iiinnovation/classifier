# UX-03：功能主线与信息层级调整

日期：2026-10-29。用户在 [主线产品审查](product-mainline-review-2026-10-29.md) 后授权调整。本轮将结果阅读、继续研究和日常记录放在前面，将维护与进阶操作放入可展开入口。

## 现在的操作路径

- 主题顶部可进入文献、比较、总结和笔记，并直接继续最近的比较／总结。长研究问题与筛选说明可展开查看。
- 文献标题直接打开研读；卡片常驻筛选与阅读记录，书目信息、移出、删除及影响预览放在“更多”。
- 空主题先添加材料，单篇先阅读；选择不足、超过 12 篇或没有模型连接时，都给出就地操作。
- AI 比较先展示草稿，已保存表格可主动打开编辑。采用后直接阅读当前比较并生成总结；整份调整和单列建议分别按需展开。
- 单个比较出处直接打开摘录，核对操作在摘录旁。条件说明、普通状态和空综合判断减少常驻展示，缺失、不可比和来源变化仍可辨认。
- 总结先展示正文；窄窗口的材料与生成区域排在正文之后。草稿尚未采用且没有保存正文时，编辑与导出不可用；已有正文的新草稿与已保存正文有明确区分。
- 首次新建总结即可写作并一次保存；材料选择中的原文片段工具按需展开。旧建议与归档成果有独立入口。
- 从全部文献保存摘录或写笔记时，可以就地选择／创建主题，再继续原来的记录。所选主题明确，原文内容与引用不会因选择归属而重填。
- 模型管理、存储用量、历史及归档进入低频入口；发送告知、立即撤销授权和具体删除范围仍可查看。

## 对审查问题的落实

| 审查项 | 本轮结果 |
| --- | --- |
| PM-01／02 | 草稿与保存正文的编辑／导出对象明确；空正文在界面与接口两处阻止导出；窄窗口正文优先 |
| PM-03／04 | 主题导航与最近工作入口置顶；文献标题承担研读，其他操作分层 |
| PM-05 | 比较草稿与旧表默认只展示一套，旧表可主动打开；调整要求与逐列建议收起 |
| PM-06／07 | 阅读中补齐主题归属；按材料数量和连接状态给出下一步 |
| PM-08／09 | 单个出处减少一次点击，核对动作进入证据查看；条件说明收起，异常保留 |
| PM-10／11 | 当前总结草稿入口去重，旧建议收起；首次正文与标题原子保存 |
| PM-12／13 | 连接配置成功明确为“未验证”；连接管理按需展开；普通说明、上限与版本数字减量 |
| PM-14／15 | 主导航统一文献／比较／总结／笔记，导入与研读名称统一；存储诊断与零项分层展示 |
| PM-16 | 比较、总结、笔记默认聚焦活动内容，归档项可展开 |

本轮改善显示层级，没有增加另一个研究模式。系统凭据保存与连接测试继续属于 D3；真实模型输出质量与真实材料的修订成本继续属于 D4。

## 保存与核对的补充修复

创建成果接口现在接受可选 `blocks`，复用现有段落、引用、长度与来源校验。标题、研究问题和首次正文一起保存到版本 1；同一请求 ID 可重试，改过内容的不同请求不会覆盖旧创建结果。旧客户端不传 `blocks` 时仍按原路径创建。

完整链路还发现：仅修改比较项的核对标记，也会使综合判断的依据摘要过期，阻止生成总结。现只在比较内容与证据未变、原依据摘要仍匹配时推进该摘要。真正修改内容、来源变化或本来已经过期的判断继续要求复核；历史快照不改写。

## 调整前后

同一套合成材料、1440×1000 与 390×844 视口。按钮数统计整页未被折叠隐藏的按钮，包含标题与全局按钮，不等于首屏按钮数；“更多”摘要不计作按钮。

主题的完整文献与成果目录仍可滚动阅读，顶部导航与最近工作入口解决了必须先滚过全部文献才能进入成果的问题。
